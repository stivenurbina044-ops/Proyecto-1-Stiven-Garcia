# Fundación Fauna Hogar 

## Descripción del Proyecto

Este proyecto consiste en el desarrollo de una maqueta web estática para la Fundación Fauna Hogar, una organización dedicada al rescate, cuidado y adopción responsable de animales.

La página fue desarrollada utilizando únicamente HTML5 y CSS3, sin el uso de JavaScript, cumpliendo con los requisitos establecidos para el proyecto académico.

---

## Objetivos

- Dar a conocer la labor de la fundación.
- Mostrar animales disponibles para adopción.
- Facilitar el contacto con la comunidad.
- Promover las donaciones y el voluntariado.
- Aplicar conceptos de diseño responsive con HTML y CSS.

---

## Tecnologías Utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Animaciones CSS (@keyframes)

## Páginas Incluidas

### Inicio (index.html)

- Banner principal
- Carrusel automático de imágenes
- Sección de información
- Misión y visión
- Eventos y rescates
- Footer

### Adopta (adopt.html)

- Catálogo de animales
- Estado disponible/adoptado
- Historias de adopción
- Proceso de adopción

### Perfil (profile.html)

- Información detallada del animal
- Estado de salud
- Características
- Animales relacionados
- Botón de solicitud de adopción

### Contacto (contact.html)

- Formulario de contacto
- Estados de error y éxito simulados
- Información de contacto
- Redes sociales
- Preguntas frecuentes
